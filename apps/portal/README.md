# Portal

Web5 User Portal - A user-friendly entry point to the Web5 ecosystem.

## Features

- **User Registration**: 6-step wizard for creating Web5 identity
- **Web5 Apps**: App store for decentralized applications
- **User Settings**: Manage profile, data, and account settings

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Port

Default port: 3004
